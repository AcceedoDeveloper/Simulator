Parts on the lines (by last cell written)

Each part enters Cell-01 every takt. When Cell-01 finishes, a row is inserted into Line_x; every later cell updates that row a few minutes after it finishes — like the plant's Usp_Insert_L1 / Usp_Upd_L1_Cn jobs.

Backend connection

In SMES open Production Flow → Source Setup, choose Simulator / rows API and enter:

Press Test connection, Save, then Sync this line now for one line at a time.

The sync then reads GET /api/phsupport/rows?table=Line_1&hours=6, …Production_Count_Line_1&hours=3 and the TagDetails* tables instead of SQL Server.
